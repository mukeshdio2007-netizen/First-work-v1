From PowerShell or Command Prompt in this folder:

## ⚛️ Modular React & TypeScript Architecture (`src/`)

For modern full-stack workflows (Next.js, Remix, Vite), modular React + TypeScript components are provided under `src/components/`:

- `src/components/Navbar.tsx`: Responsive navigation with active scroll spy and mobile drawer.
- `src/components/Hero.tsx`: Deep navy hero section featuring the floating ribbon S emblem.
- `src/components/About.tsx`: Company introduction, vision, mission, and core values.
- `src/components/Services.tsx`: 6 core technical capability cards with hover interactions.
- `src/components/Solutions.tsx`: Scalable products and research catalog with dynamic category filters.
- `src/components/Workflow.tsx`: 4-step connected development methodology (Discover &rarr; Plan &rarr; Build &rarr; Innovate).
- `src/components/WhyUs.tsx`: 6 key differentiators focused on pragmatic innovation and engineering quality.
- `src/components/Contact.tsx`: Full-stack contact form with real-time validation, status management, and reference ticket generator.
- `src/components/Footer.tsx`: Comprehensive footer with brand motto, legal modals, and social links.
