Architecture Specification

Stuzen Omnix Core

Purpose: A multi-tenant event orchestrator engineered for handling high-throughput asynchronous job dispatching with guaranteed idempotency and low overhead.

Architectural Highlights:

  • Event Sourcing: Append-only event store guaranteeing complete auditability.
  • Worker Scalability: Dynamic worker node spinning via containerized clusters.
  • Observability: OpenTelemetry integration providing sub-millisecond trace visibility.
Stack: TypeScript • Node.js • Redis Pub/Sub • PostgreSQL • Docker

Stuzen CLI & Tokens

Purpose: An open developer workflow utility automating brand token transforms from design tools directly into production CSS, Sass, and typed Tailwind theme structures.

Key Features:

  • Extracts color scales and typography rules into typed schema definitions.

  • Validates WCAG 2.1 contrast ratios automatically during compile time.
